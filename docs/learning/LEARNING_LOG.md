# Learning Log

A short entry after each meaningful task. Its purpose is to make knowledge stick and to prepare for milestone interviews and the defense.

Write the "In my own words" part **yourself, without copying from the agent**. If you can't explain something simply, that is the topic to revisit.

## Review routine (spaced repetition)

- After each task: write the entry (5 minutes).
- Next day: reread yesterday's 🔴 entries and answer their questions from memory.
- Weekly: answer all 🔴 questions of the current milestone from memory; mark ✅ or ❓.
- Before each milestone interview: go through every ❓.

## Entry template

```markdown
### YYYY-MM-DD: Task name (Milestone Mx)

**What we built:** one or two sentences.

**Concepts**
- 🔴 Concept: in my own words, and why it matters here
- 🟠 Concept: in my own words
- 🟢 Concept: one line

**Decision made (and ADR, if any):** …

**Self-check questions** (answer from memory later)
1. …
2. …

**Still unclear:** …
```
